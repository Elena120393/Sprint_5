
# Автоматизированные тесты для Stellar Burgers

Этот проект содержит набор автотестов для веб-приложения [Stellar Burgers](https://stellarburgers.nomoreparties.site). Тесты реализованы с использованием Selenium WebDriver и pytest и покрывают основные сценарии:
- Навигация по вкладкам в разделе "Конструктор"
- Вход в аккаунт через главную страницу, через кнопку "Личный кабинет", а также через переходы из форм регистрации и восстановления пароля
- Регистрация пользователя (с корректными данными и с некорректным паролем)
- Выход из аккаунта
- Переход из личного кабинета в раздел "Конструктор"

## Структура проекта

```
├── README.md                # Настоящий файл
├── conftest.py              # Конфигурация pytest и настройка Selenium WebDriver
├── helpers.py               # Вспомогательные функции (например, генерация уникального email)
├── locators.py              # Определение XPath/CSS локаторов для элементов на страницах приложения
├── test_data.py             # Данные для входа и регистрации (корректные учетные данные)
├── urls.py                  # URL адреса приложения
└── tests/                   # Папка с тестовыми сценариями
    ├── test_constructor_navigation_tabs.py  # Тесты навигации по вкладкам раздела «Конструктор»
    ├── test_login_from_homepage.py            # Тест входа с главной страницы
    ├── test_logout.py                         # Тест выхода из аккаунта
    ├── test_registration.py                   # Тесты регистрации (успешной и с некорректным паролем)
    └── test_transition.py                     # Тест перехода из личного кабинета в раздел «Конструктор»
```

## Пререквизиты

Перед запуском тестов убедитесь, что установлены следующие зависимости:
- Python 3.7+
- [Selenium WebDriver](https://www.selenium.dev/documentation/en/)
- [pytest](https://docs.pytest.org/en/stable/)
- [Chrome WebDriver](https://chromedriver.chromium.org/) (или другой браузерный драйвер, настроенный в `conftest.py`)

Для установки зависимостей можно использовать pip:

```bash
pip install selenium pytest
```

## Запуск тестов

После установки зависимостей запустите тесты командой:

```bash
pytest
```

Также можно запустить отдельную группу тестов, указав путь к нужному файлу, например:

```bash
pytest tests/test_registration.py
```

## Описание тест-кейсов

### 1. Навигация по вкладкам в разделе "Конструктор"
Проверяется, что у родительского элемента (по xpath "./..") появляется подстрока 'current' в атрибуте "class".

### 2. Вход с главной страницы
Тест проверяет возможность входа через кнопку **"Войти в аккаунт"** на главной странице. После ввода корректных учетных данных в форму входа проверяется наличие кнопки **"Оформить заказ"** на главной.

### 3. Выход из аккаунта
Данный тест проверяет сценарий выхода из аккаунта. После входа пользователь кликает по кнопке **"Личный кабинет"** для вызова меню, затем нажимает **"Выход"** и проверяется, что отображается форма входа.

### 4. Регистрация пользователя
- **Успешная регистрация:** ввод корректных данных (не пустое имя, уникальный email, пароль длиной не менее 6 символов). После регистрации ожидается переход на страницу логина.
- **Регистрация с некорректным паролем:** проверяется, что при вводе пароля, содержащего менее 6 символов, отображается сообщение об ошибке.

### 5. Переход из Личного кабинета в раздел "Конструктор"
После входа в аккаунт пользователь переходит через кнопку **"Конструктор"** и кликая по логотипу возвращается в раздел, где проверяется наличие элементов конструктора (например, вкладка "Булки").

## Дополнительные сведения
- Функция генерации уникального email определена в [helpers.py](helpers.py) и используется для предотвращения конфликтов при повторной регистрации.
- Все локаторы для элементов интерфейса содержатся в файле [locators.py](locators.py), что упрощает сопровождение тестов.
- Конфигурация Selenium WebDriver осуществляется через фикстуру в файле [conftest.py](conftest.py).

## Заключение
