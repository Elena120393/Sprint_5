# Автоматизированные тесты для приложения Stellar Burgers

В этом документе описаны автотесты, разработанные для проверки ключевых функциональностей веб-приложения Stellar Burgers. Все тесты реализованы с использованием Selenium WebDriver и pytest.

---

## Тест-кейсы

### 1. Тест переходов в разделе "Конструктор"
**Функция:** `def test_constructor_navigation_tabs(driver):`  
**Описание:**
- Проверяется корректность перехода между вкладками в разделе "Конструктор".

**Шаги:**
1. Открывается главная страница.
2. Переход осуществляется по вкладкам: **"Булки"**, **"Соусы"** и **"Начинки"** с использованием кликов.
3. Проверяем, что на странице присутствует элемент-кнопка каждой вкладки. 

---

### 2. Тест входа с главной страницы
**Функция:** `def test_login_from_homepage(driver):`  
**Описание:**
- Проверяется процесс входа в аккаунт через кнопку **"Войти в аккаунт"** на главной странице.

**Шаги:**
1. Открывается главная страница.
2. Нажимается кнопка **"Войти в аккаунт"**.
3. Заполняется форма логина (email и password).
4. Отправляется форма входа.
5. После входа открывается главная страница.
6. Проверяется наличие кнопки **"Оформить заказ"**.

### 7. Тест успешной регистрации
**Функция:** `def test_registration_success(driver):`  
**Описание:**
- Проверяется корректность процесса регистрации с использованием верных данных.

**Шаги:**
1. Открывается страница регистрации.
2. Вводятся корректные данные:
   - **Имя:** не пустое значение.
   - **Email:** в формате `login@domain`, например, `test_xxx@ya.ru`.
   - **Пароль:** не менее 6 символов.
3. После нажатия на кнопку **"Зарегистрироваться"** проверяется появление индикатора успешной регистрации (например, переход в раздел **"Личный кабинет"**).

---
